The budget clause was degenerate the design mistake that mattered most
I gated the protocol directly on WHO's weekly budget. It sounds rigorous. Delhi spends that budget by Tuesday, so every clause fired for every class every day — all four classes returned byte-identical decisions and the protocol stopped discriminating entirely.
Separated the two jobs. WHO stays the yardstick impact is reported against; what the protocol enforces is avoidable dose — the part of today's exposure a school can still choose not to take. The difference between a true statement and a usable tool.
150 schools that were never in Delhi found by drawing the map
Schools were collected from a bounding box. A box around Delhi also contains Gurugram, Noida and Faridabad. 16% of the headline count was wrong — and the numbers alone never showed it.
Drawing the real NCT boundary made the error visible: points sat outside the border. Now clipped point-in-polygon. 922 became 772, with a test.
Cedar has no floating-point type every request silently failed
Every authorization returned data did not match any untagged enum because the evidence was passed as floats.
Evidence is rounded to whole µg/m³, metres and percent on the way in, and thresholds are written in the same units, so nothing a threshold turns on is lost.
A selector that hid five panels and a units error in a health tool
[data-on=1] is not a valid CSS selector — an unquoted attribute value cannot begin with a digit — so every tab pane stayed hidden while its content sat in the DOM. Separately, text-transform:uppercase turned µg into "MG": milligrams, a thousand-fold error.
Both found by looking at the rendered page, not the code. Units now opt out of transforms, and the selector is quoted.
The guard caught the language model three times during the build — an invented figure, "cancelled" when nothing was cancelled, and "all classes" when one class was still outside. That is the whole argument for keeping it away from the decision.
