This morning's decision

Four questions have to be answered before the gates open: does assembly happen outside, does the games period happen, do the windows stay open, who gets a mask. Saans answers them per class, because a class carrying children on the respiratory register is not in the same position as one that is not. Every row cites the clause that produced it.

03

Dose, not index

An AQI number is a colour for a city for a day. What a child takes in is a dose: concentration × time outdoors × how hard they are breathing. A child at games moves roughly three times the air through their lungs, so the same reading delivers three times the dose. That product is the only quantity a school can actually spend or save, so it is what Saans budgets — against the WHO guideline week of 150 µg·h.

04

What the protocol is worth

Replayed over real days that actually happened, with measured air — no modelling of our own. The point is not that the protocol fires. It is that on clean days it stays out of the way, and on bad days it recovers about half the dose a child would otherwise have taken in.

05

The protocol, as code

This is the school's circular written in Cedar, AWS's open-source policy language. It is not a prompt. No language model reads it, writes it, or can talk its way around it: Saans may only hold an activity outdoors if Cedar returns ALLOW for that class, that period and that hour's evidence. A principal can argue with a clause and change a number without touching a line of application code.

06

Run the 05:45 job

The whole morning, on demand: decide, draft the notice, write the ledger, store the notice, send it. The agent drafts the opening line a parent reads first — and a guard checks it against the record, because a small model writing a fluent sentence with a wrong number in it is the likeliest way this hurts somebody. Rejected drafts fall back to the deterministic summary, and the page says so.

07

Built on AWS

The Build It path: AWS open-source tooling on a laptop, no AWS account and no card. Cedar decides, Strands Agents SDK runs the agent against a local model, and LocalStack stands in for four managed services. The same boto3 calls run unchanged against real AWS — SAANS_AWS=real drops the endpoint override.
