Tech stack and architecture

Python throughout. Nothing in the chain needs an API key, a card, or a paid account — every dependency is free tier or open source, which is a design constraint, not an accident.

1 · Evidencefree, no key
Open-Meteo CAMS
Hourly PM2.5 forecast and the mixing-layer height, for any coordinate. ERA5 for measured history.
OpenStreetMap
772 Delhi school locations and the NCT boundary, ODbL. Clipped point-in-polygon so Gurugram is not counted as Delhi.
2 · Decisiondeterministic
exposure.py
Dose = µg/m³ × hours outdoors × breathing rate, against the WHO guideline week of 150 µg·h.
decide.py
Prices every option for every period: hold it, move it to the cleanest hour, or take it indoors.
Cedar AWS OPEN SOURCE
9 policy clauses. A period stays outdoors only on an allow. Every denial cites its clause. Fails closed.
3 · Prose onlynever decisions
Strands Agents SDK AWS OPEN SOURCE
Four tools over the forecast, the protocol, the ledger and the clause text. Runs on a local model — no key, no spend.
guard()
Rejects a draft that states an unsupported figure, claims indoors is safe, says "cancelled", or flattens a mixed decision. Falls back to the deterministic summary and says so.
4 · Record and deliverAWS services
DynamoDB AWS
The decision ledger — every call, its evidence hash, its clauses.
S3 AWS
The bilingual notice, stored exactly as it went home.
EventBridge AWS
cron(15 0 * * ? *) — 05:45 IST, before the gates open.
SES AWS
Delivery to the principal and the register's parents.
No language model decides anything that affects a child's lungs. Cedar decides; the model writes one sentence, behind a guard.
AWS Gate — must pass to proceed Free, keyless data or plain Python

Build It path: LocalStack stands in for the four managed services, so this runs with no AWS account and no card. The same boto3 calls run unchanged against real AWS, and deploy/aws_deploy.py puts it on Lambda behind a public Function URL inside the always-free tier. 67 tests.
